## 目录与使用

- `ref-code/`：上游源码、原许可证与随附文档。
- `ref-paper/`：PDF、文本、手册、文献索引及引用导出。
- `analysis/`：中文报告、图表源文件、原文图表摘取、数据表和证据预览；`figures/`中的 `build_figures.py` 可重绘自绘图。
- `metadata/`：GitHub/Crossref/OpenAlex/arXiv原始元数据及清单。
- `scripts/`：采集、索引生成和核查脚本。
- `logs/`：检索记录、版本处理与质量检查。

网络采集脚本会访问当时的上游默认分支，不要用重新执行采集来覆盖已经用于报告的固定快照。后续直接维护无版本后缀的最终报告；原始资料及其来源记录用于追溯。无需运行任何脚本即可阅读现有成果。

报告和索引中的资料引用均采用本地相对路径；仅有元数据的条目明确指向元数据记录。上游源码、论文原件及采集元数据保留原始版本和来源标识。

## 仓库收录范围

保留参考源码及构建/测试脚本、原许可证、论文与手册、分析报告、PNG/SVG/PDF 配图、原始数据表和来源记录。`.gitignore` 排除参考实现附带的网格、二进制策略表、仿真结果、大型测试数据以及重复 TIFF 导出和编译缓存；本地已有文件仍保留。

参考源码来自清单中的固定提交，在线仓库为精简收录，不包含完整算例数据，不能直接视为可运行全部上游测试的发行包。`metadata/SHA256SUMS` 校验已纳入 Git 的资料；原始归档的提交和校验记录仍保留在来源清单中。
