日期：2026-10-28；任务：评审意见②，本地知识库及对比分析。用户明确不需要在线推送。

## 检索路线

采用 `nature-academic-search` 的multi-source-search流程。学术MCP本会话未提供可调用接口；web搜索调用返回 `Invalid URL (POST /v1/alpha/search)`，改为Python requests访问公开API与原始网站。

1. GitHub官方仓库API确认项目身份、默认分支和提交；按commit从codeload下载源码。
2. Crossref关键词检索及逐DOI核验；初始并发查询部分429，改为OpenAlex发现与串行DOI查询补齐。Crossref原始响应保存在metadata。
3. arXiv API、摘要页及PDF；以提交历史确认文献日期和版本。P01等预印本与期刊论文合并为单条，保留两种日期。
4. 官方网站和仓库文档进行反向核对，阅读重点论文性能表和实现章节，再回到代码确认关键路径。

原始查询包含：PyFR GPU performance、GALÆXI GPU discontinuous Galerkin、HORSES3D GPU、HiFiLES GPU、MFEM GPU high order finite element、matrix free high order GPU finite element、GiMMiK、libCEED、GPU discontinuous Galerkin implicit solver。标题检索进一步覆盖FLEXI、GPU Algorithms for Efficient Exascale Discretizations、GPU DG incompressible solver及图书。

此为针对评审问题的工程调研，采用关键词和引文追踪，不声称穷尽近十年全部相关论文。纳入条件：直接描述上述框架、GPU高阶核/内存/通信、隐式预条件或可替换后端；排除只提及关键词而无直接实现关联的资料，以及重复预印本/正式出版记录。

## 主要版本处理

- GALÆXI main提交日期2024-10-11；2026年的跨架构论文只算论文证据，不将其功能写成本地代码已经实现。
- PyFR与MFEM为2026-10-28取回的默认开发分支，不将其冠以未核实的正式版本号。
- HORSES3D与HORSES3D-GPU分别保存，避免把主版能力直接投射到GPU版。
- HiFiLES快照提交日期2016-01-29，注明历史性质。
- arXiv首次提交和最新版本标识已保存；期刊DOI逐条核验。FLEXI/MFEM期刊卷期为2021，不能由DOI中的2020推断出版年。
- GitHub archive为源码快照，未含.git历史；不主动递归抓取所有第三方依赖。归档中的绝对路径/含上级跳转的符号链接未解出，避免链接指向原开发者环境；源码主体保留。此快照用于审阅，不宣称开箱即编译成功。
